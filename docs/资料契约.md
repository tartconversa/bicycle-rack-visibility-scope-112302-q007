# 资料契约

本目录只含本地合成记录，不包含真实驾驶员、车辆或道路资料。新闻报道描述的是厂商发布信息及公开说明，不是本资料集中的实测结论。

| 文件 | 字段 | 记录数 |
| --- | --- | ---: |
| `vehicles.csv` | `vehicle_id`, `model`, `hardware`, `region`, `camera_config` | 35 |
| `rack_installations.csv` | `installation_id`, `vehicle_id`, `rack_model`, `mount_position`, `load_state`, `valid_from`, `valid_to`, `review_state` | 47 |
| `drive_events.csv` | `trip_id`, `vehicle_id`, `version`, `started_at`, `rear_visibility`, `upload_state`, `intervention_id` | 60 |
| `rear_observations.csv` | `observation_id`, `trip_id`, `target_class`, `camera`, `review_state`, `detected`, `review_batch` | 41 |
| `trial_scopes.csv` | `scope_id`, `model`, `hardware`, `rack_model`, `region`, `status`, `vehicle_count`, `source_version` | 18 |

输入文件之间通过明确的标识字段关联。记录时间均为 UTC 或 ISO 日期。缺失覆盖、待复核和撤回状态是有效业务事实，不能自动解释为零事件或成功。事件标签、回执、版本和授权范围以各行记录为准。所有示例数值由固定种子构造，仅供本地数据流程开发与测试。

## 字段取值与业务语义

### 车架安装登记 `rack_installations.csv`

- `valid_from` / `valid_to` 为闭区间，按行程日期（UTC）判定当时是否生效；车架拆装登记晚于车辆登记是允许的。
- 同一车辆同一时刻存在多条生效登记属于**配置冲突**，应用不得任选一条，须标记为 `conflicted` 并进入否决/重核。
- `review_state` 是车架登记的复核来源，独立于后方目标的复核来源：
  - `confirmed`：已确认，可作为生效配置证据；
  - `pending`：待复核，配置存在但未确认，不能单独支撑试用结论；
  - `revised`：已更正/撤回，引用它的待执行名单须重新核验。
- `mount_position`：`hitch`（拖车钩）/ `roof`（车顶）/ `rear-door`（尾门）。
- `load_state`：`empty` / `loaded` / `unknown`；`unknown` 不满足载荷覆盖要求。

### 行程 `drive_events.csv`

- `version`：当前仅 `V14`、`V15`。V15 是新功能证据版本，V14 行程只作历史基线，不进入 V15 评估。
- `rear_visibility`（后方摄像头可见区域，与是否安装车架是两件事）：`clear` / `partial` / `occluded`。
- `upload_state`：`complete` / `late` / `missing`；`missing` 表示资料缺失，对应「无法评估」，不得当作零事件。
- `intervention_id`：空值与占位编号 `E-00` 都不是真实接管；其余编号（如 `E-04`）为真实驾驶员接管，是否决性硬红线。

### 后方目标记录 `rear_observations.csv`

- 仅 `camera=rear` 的记录参与后摄判定；`side` 为侧摄背景信息。
- `review_state`：`confirmed` / `uncertain` / `revised`，与车架登记复核相互独立。
- `detected`：`yes` / `no`。只有 `confirmed + yes` 计为确认识别；`confirmed + no` 计为未识别。
- 行程没有任何后摄记录时为「未观测」，**不是识别成功**。
- `review_batch` 标识复核批次，新批次导入用于影响分析。

### 试用范围 `trial_scopes.csv`

- `status`：`proposed`（拟建，未生效）/ `partial`（受限试用）/ `accepted`（已接受）。
- `source_version` 是名单自身的配置证据版本标签；评估应用另有行程证据版本，溯源输出中两者并列保留。
- 应用只输出建议状态（含 `hold` 暂停建议），不自动改写本文件；变更需评估负责人审批。

## 证据分级（应用输出口径）

| 分级 | 触发条件 |
| --- | --- |
| `confirmed_recognition` 确认识别 | 后摄记录复核 confirmed 且检出 yes |
| `not_recognized` 未识别 | 后摄记录复核 confirmed 但全部未检出 |
| `review_uncertain` 复核不确定 | 后摄记录无 confirmed，仅有 uncertain |
| `review_revised` 复核已更正 | 后摄记录出现 revised，证据不可用 |
| `unobserved` 未观测 | 后摄无任何目标记录 |
| `not_evaluable` 无法评估 | 资料缺失（upload missing）或后摄完全遮挡 |

## 导入规则

- CSV 一律按 UTF-8 BOM 读取；表头、枚举值、日期、整数、主键唯一性与跨表引用均强制校验，违规时报错并注明文件名与行号。
- 应用仓库按业务主键做幂等 upsert（车辆/登记/行程/观测/范围各自主键），重复导入不产生重复记录，每次导入留存批次溯源。
- 历史行程证据按当时安装状态固化；车架登记更正只影响尚未生效的名单，不回改已发生行程。
